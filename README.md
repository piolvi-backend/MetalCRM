# MetalCRM

Мини-CRM для пункта приёма металлолома. Дипломный проект и учебное приложение на ASP.NET Core с использованием Clean Architecture.

## О проекте

Приложение автоматизирует работу небольшого пункта приёма металлолома. Владелец получает простой инструмент для ведения базы клиентов и управления ценами без лишней сложности и без регистрации для сотрудников (рассчитано на 2-3 доверенных аккаунта).

Планируемые возможности:
- База клиентов с поиском и сортировкой (PostgreSQL).
- Админ-панель с CRUD операциями над клиентами.
- Логи операций по клиентам.
- Управление ценами и пунктами приёма для лендинга.
- Публичный лендинг с актуальной информацией.

## Архитектура

Проект построен по принципам Clean Architecture. Зависимости направлены внутрь, к домену.
